# المعلّم الذكي

تطبيق ويب عربي لحل الواجبات وشرح الدروس من صورة الورقة: المعلم التفاعلي، كبسولة الأم، الحل النموذجي، صحّح واجبي، الحل على الورقة، عدسة الكلمات.

- يعمل من المتصفح ويُضاف إلى الشاشة الرئيسية (PWA).
- المفاتيح (Gemini / OpenRouter / ElevenLabs) تُحفظ في جهاز المستخدم فقط.
- الإصدار الحالي: v1.3
